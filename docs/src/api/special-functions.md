# Special Functions

Layer 0 mathematical primitives: spherical Bessel/Hankel functions, associated Legendre
derivatives, and Gauss-Legendre quadrature mappings.

These functions are thin compositions around `SpecialFunctions.jl`,
`LegendrePolynomials.jl`, and `FastGaussQuadrature.jl`.
